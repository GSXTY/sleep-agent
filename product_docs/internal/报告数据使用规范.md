# 报告数据使用规范

> 内部资料：字段处理规则与数据边界，不对用户展示。

## 三、数据使用注意事项

1. 字段有效性：部分压力字段仅对应特定工作模式，非对应模式下字段为空，属于正常情况，需按「缺失即说明」原则处理，禁止补0。 2. 数值范围：压力单位为hPa（百帕），部分原始导出值为放大100倍的整数（如2500实际为25hPa），使用前需做单位换算校验。 3. 碎片记录：治疗时长＜240分钟的记录为碎片治疗，结论参考价值有限，输出时需附加提示。 4. 数据层级：本数据为单晚汇总数据，无分钟级明细，无法做事件聚集时段、逐时趋势分析。 5. 合规说明：所有数据属于用户敏感健康数据，存储、传输、使用需符合医疗数据隐私规范。
