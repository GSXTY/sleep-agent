# 报告指标说明

> 来源：睡眠呼吸设备报告导出字段释义（原件已归档到 product_docs/_originals/）。用于解释 App 与报告中各项指标的含义。

睡眠呼吸设备报告导出CSV字段释义文档 文档版本：V1.0 适用数据：70天治疗报告导出CSV（L2级单晚汇总数据） 数据用途：单晚治疗报告生成、周期趋势分析、用户治疗数据查询

## 一、数据概述

本CSV为睡眠呼吸设备的单晚治疗汇总数据（L2级报告导出数据），每行代表一条完整的夜间治疗记录，共包含用户标识、治疗时长、呼吸事件、漏气、压力、通气量、评分等全维度指标。数据来源于设备分钟级采样聚合计算，可直接用于生成单晚报告、统计周期趋势，是Agent数据查询与报告生成的核心数据源。

## 二、字段详细释义

### 2.1 基础标识类

| 字段名 | 中文释义 | 单位 | 详细说明 |
|---|---|---|---|
| 用户ID | 用户唯一标识 | - | 系统内用户的唯一编号，用于关联用户账号与治疗数据 |
| 设备ID | 设备硬件唯一标识 | - | 呼吸机设备的MAC地址/硬件序列号，单用户可绑定多台设备 |
| PiCode/产品编码 | 产品型号编码 | - | 设备的官方产品型号编码，对应不同机型、配置 |
| 设备类型 | 设备类型编码 | - | 设备品类编码，区分不同系列的睡眠呼吸治疗设备 |

### 2.2 时间与时长类

| 字段名 | 中文释义 | 单位 | 详细说明 |
|---|---|---|---|
| 记录时间（yyyy-MM-dd HH:mm:ss） | 记录归属日期 | 日期 | 本条治疗记录归属的自然日 |
| 开始时间 | 本次治疗开始时间 | 时间 | 设备启动治疗的精确时间点 |
| 结束时间 | 本次治疗结束时间 | 时间 | 设备停止治疗的精确时间点 |
| 治疗时长 | 实际治疗总时长 | 分钟 | 本次治疗的有效持续时长；不足240分钟为碎片记录，结论参考价值有限 |
| 实际日期/上传时间 | 数据上传/统计日期 | 日期 | 数据同步到服务器的日期，部分场景下与治疗日期一致 |
| 解析时区 IANA ID | 数据解析时区 | - | 时间字段对应的时区标准，如Asia/Shanghai、Asia/Hong_Kong |

### 2.3 治疗模式类

| 字段名 | 中文释义 | 单位 | 详细说明 |
|---|---|---|---|
| 当日工作模式 | 治疗工作模式 | 编码 | 1=CPAP（固定单水平）、2=AutoCPAP（自动单水平）、3=S（自主通气）、4=AutoS（自动自主）、5=T（时间控制）、6=AutoST（自动双水平）、7=IVAPS（智能容积伺服）；单晚可存在多种模式切换 |
| 各工作模式使用时长（分钟）JSON | 分模式时长统计 | 分钟 | JSON格式，键为模式编码，值为对应模式的累计使用时长 |
| 当日压力释放档位去重 | 压力释放档位 | 编码 | 当日使用过的压力释放档位，逗号分隔；对应设备的呼气压力释放功能等级 |
| 固件版本 | 设备固件版本 | - | 设备内置控制程序的版本号 |
| 硬件版本 | 设备硬件版本 | - | 设备硬件的版本迭代标识 |

### 2.4 呼吸事件核心指标（AHI体系）

核心说明：AHI = AI + HI，是评估呼吸暂停严重程度的核心指标，正常值＜5次/小时。

| 字段名 | 中文释义 | 单位 | 详细说明 |
|---|---|---|---|
| AHI | 呼吸暂停低通气指数 | 次/小时 | 每小时呼吸暂停+低通气的总次数；核心分级指标：<5正常，<15轻度，<30中度，≥30重度 |
| 呼吸暂停次数（当日 type=2 apnea_count 合计） | 总呼吸暂停次数 | 次 | 当日所有呼吸暂停事件的总次数（气道完全闭塞） |
| 呼吸暂停总持续时间（秒，type=2 apnea_duration 合计） | 呼吸暂停总时长 | 秒 | 当日所有呼吸暂停事件的累计持续时间 |
| 睡眠呼吸暂停指数 AI | 呼吸暂停指数 | 次/小时 | 每小时呼吸暂停次数；AHI的组成部分之一，仅统计完全暂停事件 |
| 中枢性睡眠呼吸暂停次数（当日 type=2 ca_count 合计） | 中枢性呼吸暂停次数 | 次 | 中枢性呼吸暂停事件总次数（由中枢神经驱动不足导致，而非气道阻塞） |
| 当日中枢性呼吸暂停总时长（秒） | 中枢性呼吸暂停总时长 | 秒 | 中枢性呼吸暂停事件的累计持续时间；表头存在同名字段冗余，靠近「中枢性睡眠呼吸暂停次数」的字段为有效值 |
| 中枢性睡眠呼吸暂停指数 CAI | 中枢性呼吸暂停指数 | 次/小时 | 每小时中枢性呼吸暂停次数；占比低提示问题以阻塞型为主 |
| 低通气次数（当日 type=2 hypopnea_count 合计） | 低通气事件次数 | 次 | 低通气事件总次数（气道部分狭窄，气流下降但未完全中断） |
| 低通气总持续时间（秒，type=2 hypopnea_duration 合计） | 低通气总时长 | 秒 | 当日所有低通气事件的累计持续时间 |
| 低通气指数 HI | 低通气指数 | 次/小时 | 每小时低通气次数；AHI的组成部分之一，代表气道部分狭窄事件 |

### 2.6 压力类指标

|---|---|---|---|

| 治疗压力P95 | 治疗压力P95分位值 | hPa | 95%时间内不会超过的治疗压力；仅1/2（CPAP/AutoCPAP）模式统计 |

| 平均吸气压力 | 平均吸气压力 | hPa | 吸气相的平均输出压力；仅3/4/5/6模式统计 |
| 呼气压力P95 | 呼气相压力P95 | hPa | 95%时间内呼气相压力不超过该值；仅3/4/5/6模式统计 |
| 平均呼气压力 | 平均呼气压力 | hPa | 呼气相的平均输出压力；仅3/4/5/6模式统计 |
| 呼气末正压PEEP P95 | PEEP P95分位值 | hPa | 呼气末正压的95分位值，维持气道开放的基础压力；仅3/4/5/6模式统计 |
| 平均呼气末正压PEEP | 平均PEEP | hPa | 治疗全程的平均呼气末正压；仅3/4/5/6模式统计 |

## 阅读提示

- 部分压力字段只在双水平等特定模式下有数值；空值表示该模式不适用，不代表设备故障。
- 治疗时长不足 240 分钟的记录属于碎片治疗，指标参考价值有限。
- 本数据为单晚汇总，不包含分钟级明细，因此不能说明事件发生在几点。
