呼吸触发灵敏度 吸气灵敏度：设置范围为1/2/3档，默认2，1灵敏度最高 呼气灵敏度：设置范围为1/2/3档，默认2，1灵敏度最高 备用频率 设置范围：关/5~35bpm，步长1bpm，默认关 噪声 呼吸机工作模式为CPAP模式，输出压力为10 hPa时，测得平均 A 计权声压级≤28dB(A)，平均A计权声功率级≤36dB(A)，不确定度2dB。 压力释放功能 设置范围分0，1~3共4档可调。1~3每个档降10%、20%、30%。 无线传输功能 呼吸机通过蓝牙进行数据传输。 自动开机功能 应能设置自动开机功能的开启与关闭。当自动开机功能开启时，使用者戴上呼吸面罩并深呼吸几次后应自动启动治疗机并输出预设压力；当自动开机功能关闭时，出气口流量变化应不会启动呼吸机，只能通过手机APP界面或面板上按键启动。

自动关机功能 应能设置自动关机功能的开启与关闭。当自动关机功能开启、延迟关机功能关闭时，呼吸机识别不到呼气周期，并持续8s±5s，呼吸机应自动停止输出压力；当自动关机功能关闭时，呼吸机只能通过手机APP界面或面板上对应按键停止输出压力。 延迟关机 能设置延迟关机功能的开启与关闭。当延迟关机功能开启时，按停止按钮，呼吸机以不大于3 hPa的压力继续工作约15分钟后呼吸机停止输出；当延迟关机功能关闭时，按停止按钮呼吸机直接停止输出。 漏气提示功能 在关闭自动停机情况下，面罩脱落或者管路脱落及其他引起的大量漏气（出气口即时流速变化大于50%），并以变化后的流速持续3s，应提示漏气。误差应为±2s。 参数锁定功能

设备在工作时，核心临床参数将锁定，仅允许调节舒适性设置。 记录功能 能通过 APP和SD卡记录患者治疗数据。 输出压力实时显示 主机屏幕实时显示工作压力，误差为±(满刻度读数的2%+实际读数的4%)。 自动漏气补偿 当呼吸机设定工作压力小于或等于当前机型最大治疗压力(≤20hPa或25hPa)，漏气量不大于70 L/min时，压力误差士1hPa。 通气管路面罩接口管径 适配15mm标准管路。 通气管路面罩接口处的最高压力 正常状态下，当前机型的最大治疗压力/呼气压（20hPa或者25hPa）；单一故障状态下，最大极限压力为40 hPa。 加温湿化器 a）加温湿化器温度调节范围 分Off,1～8挡可调 b）患者连接处气体温度

应≤43℃ c）湿化系统输出 测试环境在15℃到35℃时，湿化系统具有不少于12mg/L的湿化系统输出能力。 加温湿化器压降 最大值：于60L/min流量时为0.4 hPa。 加温湿化器水箱容量 最高水位可储液308mL，最低水位可储液43mL，储液量应满足8小时使用时长。 两次注水时间间隔 8小时（湿化等级为8挡，压力为20hPa的条件下）。 注：静态压力稳定度、动态压力稳定度和湿化输出在最不利（最大压力）情况下测定。
