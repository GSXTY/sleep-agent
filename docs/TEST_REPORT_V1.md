## 运行检查

- `python chat.py`：可以进入交互对话。
- `python chat.py --no-llm "滤芯多久换一次"`：规则版产品文档回答正常。
- `python chat.py --verbose`：终端显示请求级日志。
- `/status`：显示聊天模型、向量模型、索引和降级状态。
- `python probe_server.py`：HTTP 探针可以启动并返回结构化响应。
- `logs/agent.log`：请求日志自动落盘并按大小轮转。

## 结论

当前版本通过内部功能、安全、日志和检索基线验证，可作为 V1.0 基础闭环版交付。测试结果是当前样板数据和评估集上的结果，不等于真实患者数据或生产环境准确率。
