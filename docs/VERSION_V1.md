# 睡眠呼吸产品助手 V1.0 版本说明

- 版本：1.0.0
- 日期：2026-10-22
- 状态：内部验收版
- 运行形态：Python 命令行 + 标准库 HTTP 探针

## 版本目标

完成一个可运行、可验证、可对接前端的睡眠呼吸产品助手基础闭环，当前不接入真实患者后台和正式 App。

## 本版能力

- 安全边界：红旗症状、调压、诊断、用药、停用类请求优先拦截，不进入模型和检索。
- 产品知识问答：Ollama + `bge-m3` 稠密检索与 BM25 稀疏检索，经 RRF 融合；向量不可用时降级为纯关键词。
- 设备数据问答：从确定性事实层读取单晚指标，模型不生成数值。
- 多晚分析：支持 7/14/30 天窗口、两晚对比、近期/此前阶段对比、
  平均值/中位数/范围/走势/波动与偏离日，并提示记录缺口和碎片夜。
- 单晚报告：确定性生成文本报告和结构化报告。
- 通用对话：DeepSeek 负责语言组织，事实和产品资料仍由代码提供。
- 工程能力：`UserQuery` / `AgentResponse` 契约、请求 ID、文件日志、轮转、HTTP 探针和契约测试。

## 关键约束

- 零第三方运行时依赖，只使用 Python 标准库。
- 缺失字段输出“未提供”，不填 0、不推测。
- 所有数值来自确定性代码，大模型只组织语言。
- 安全拦截优先于模型和检索。
- 真实原始数据放 `.local/`，不进入代码仓库。

## 已知限制

- 当前只有 `DEMO-USER` 样板数据；`user_id` 已贯穿接口，但真实多用户数据源尚未接入。
- 报告数据来自样板或本地导出，不能代表真实患者人群。
- 尚未接入正式 App、后端鉴权、限流和完整 API 网关。
- 周期报告、分钟级事件明细和时段聚集分析尚未完成。

## 下一阶段

接入真实后台数据源和正式 App 入口。当前内部契约保持不变，后端字段通过适配层映射到 `UserQuery`。
