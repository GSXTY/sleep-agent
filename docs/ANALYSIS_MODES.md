# 设备数据分析功能说明

## 1. 能力边界

当前版本对设备记录做确定性的描述性分析：

- 本晚指标概览；
- 最近两晚指标对比；
- 最近阶段与此前阶段的均值对比；
- 多晚平均值、中位数、最低值、最高值和首末变化；
- 线性走势、波动程度和偏离窗口常见范围的单晚；
- 记录覆盖、无记录日、碎片夜等数据质量；
- 根据确定性数据给出低风险使用建议。

不提供疾病诊断、不判断病情严重程度，也不建议用户自行调整治疗压力或设备参数。
“偏离常见范围”只表示该晚数值相对本窗口有统计偏离，不等于健康异常。

## 2. 时间窗口

综合分析默认按最近 **30 个日历日**读取当前夜及之前的记录。问法可以收窄或明确窗口：

| 问法 | 窗口 |
|---|---|
| `分析一下` | 30 天，数据不足时明确降级 |
| `分析一下最近一周` | 7 天 |
| `分析最近14天` | 14 天 |
| `分析最近30天/最近一个月` | 30 天 |

数据只有 7 天时，不会把 7 天结果包装成“30 天结论”，会写明实际覆盖日期和夜晚数。

## 3. 综合分析

触发示例：

```text
分析一下
分析一下最近30天的趋势、阶段变化和异常
帮我分析一下最近一周的平均、变化，并和上一晚对比
综合分析这几天的数据
对比分析一下最近的记录
```

模式名为 `数据分析`，固定包含：

1. `【先给结论】`：先说明覆盖范围，再归纳主要变化、近期阶段变化、
   最大波动和记录缺口；
2. `【数据概览】`：当前选定夜晚的核心指标；
3. `【主要发现】`：基于规则事实提取的正向项和待观察项；
4. `【与上一晚对比】`：治疗时长、评分、AHI、平均/P95 压力、
   平均/P95 漏气和大漏气时长；
5. `【阶段对比】`：最近最多 7 晚与此前最多 7 晚的均值变化；
6. `【窗口统计】`：使用时长、AHI、压力、漏气、潮气量、呼吸频率、
   分钟通气量的有效夜晚数、平均值、中位数、范围、首末变化、
   走势和变异系数；
7. `【值得回看】`：偏离窗口常见范围的日期及具体指标；
8. `【建议】`：结合趋势、漏气、记录缺口和碎片夜给出低风险建议；
9. `【边界】`：数据解释与医疗边界。

因此“对比”不是单独附加的能力，而是综合分析固定输出的一部分。
统计表用于展示证据，排在前面的文字结论用于回答“这些数据说明了什么”。

## 4. 明确的两晚对比

触发示例：

```text
上一次的报告和前一次相比
2026-10-13 和 2026-10-15 对比
```

模式名为 `报告对比`，只输出两晚指标对照表，适合用户明确要求比较两个夜晚。

## 5. 多晚变化与平均

触发示例：

```text
这几天数据有什么变化
对比一下最近几天的数据
最近一周的数据怎么样
最近30天数据怎么样
```

模式名为 `趋势分析`，同样先给结论，再给阶段对比和窗口统计。

带具体指标的趋势仍保持原设备数据回答，例如：

```text
最近 7 晚 AHI 趋势
最近30天 AHI 趋势
```

单指标趋势会输出有效夜晚数、平均、最低、最高、首末变化、走势和波动，
不会只重复当前一晚数值。

## 6. 数据质量规则

- 一晚一条记录，按 `record_date` 去重并排序；
- 无记录日无法区分“未使用”还是“未上传”，不擅自补零；
- 治疗时长不足 4 小时的夜晚标记为碎片夜，但仍保留并提示；
- 缺失指标不参与该指标的均值和趋势计算；
- 少于 6 个有记录夜晚时，不做近期/此前阶段对比；
- 少于 8 个有记录夜晚时，不做单个夜晚的稳健偏离判定。

## 7. 路由优先级

```text
综合分析（含具体指标时除外）
→ 多晚趋势
→ 明确两晚对比
→ 单指标设备数据
```

“分析一下漏气”仍只回答漏气，不会被扩大成整份综合分析。
