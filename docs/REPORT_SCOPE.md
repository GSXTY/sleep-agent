# 报告与情况查询范围规则

## 1. 未指定范围先追问

以下问法不再默认生成单晚报告：

```text
生成报告
出个报告
我的情况怎么样
最近使用情况
数据正常吗
```

Agent 返回模式 `范围确认`，并提供三个 `type="scope"` 的候选：

1. 单晚 / 最近一晚；
2. 近 7 天；
3. 近 30 天。

候选的 `value` 可以直接作为下一轮问题发回。
如果用户在范围确认后只回复“单晚”“一周”或“一个月”，也会继续上一轮报告流程。

“生成报告”只认当前这句话里明确写出的范围。即使上一轮刚查过某一天，也不会用上一轮日期
跳过范围确认；“我的数据正常吗”这类追问可以沿用上一轮明确过的范围。

## 2. 明确单晚

下列问法直接取指定夜晚：

```text
生成昨晚报告
生成今天报告
生成 2026-10-15 的报告
2026-10-13 的情况
前一天晚上的情况
```

如果那一天没有记录，进入 `时间确认`：

- 提供“上一次使用（最近记录日期）”；
- 同时提供最近几个可用日期；
- 用户可以改说任意具体日期。

“今天”同样按系统日期判断。今天没有记录时，不会拿最近一晚冒充今天。

## 3. 近 7 天报告

触发词包括：

```text
这一周
本周
这周
近7天
最近一周
周报
```

Agent 生成 `报告生成（周期）`，使用截至当前选择日期之前 7 个日历日的已有记录。
如果只有更少的记录，就按实际有记录夜晚计算并写明日期范围。

## 4. 近 30 天报告

触发词包括：

```text
最近一个月
近一个月
近30天
本月
月报
```

Agent 使用最近 30 个日历日的已有记录。若不足 30 天：

- 不停止回答；
- 按已有记录计算；
- 明确说明实际日期范围、有记录夜晚数和“不能当作完整 30 天基线”。

## 5. 与普通分析的边界

以下问题仍走针对性的趋势或指标模式，不强制生成整份周期报告：

```text
这几天数据有什么变化
最近 7 晚 AHI 趋势
最近30天 AHI 趋势
分析一下漏气
```

只有用户明确要“报告/情况”，或没有范围而需要先确认时，才进入报告范围流程。
